# 🏡 ArchViz AI – AI-Powered Architectural Visualization

## 📌 Overview
ArchViz AI is an AI-powered architectural visualization project that transforms architectural sketches into photorealistic images using Stable Diffusion 1.5 and ControlNet Canny.

The goal is to preserve the original architectural structure while enhancing visual quality, materials, lighting, and environmental details.

## 🎯 Objectives
- Transform architectural sketches into realistic renders.
- Preserve building geometry using ControlNet Canny.
- Enhance materials, lighting, and visual details.
- Explore AI applications in architectural design.

## 🛠️ Technologies
- Python
- PyTorch
- Stable Diffusion 1.5
- ControlNet Canny
- Hugging Face Diffusers
- OpenCV
- Google Colab (Tesla T4 GPU)

## ⚙️ Workflow
1. Upload an architectural sketch.
2. Apply Canny Edge Detection.
3. Use ControlNet to guide image generation.
4. Generate a photorealistic architectural rendering.
5. Evaluate the generated result.

## 🖼️ Results
The initial experiment successfully transformed a modern villa sketch into a photorealistic architectural rendering while preserving its main structural elements.
